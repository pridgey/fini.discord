# Archived commands

The first Finicards game's commands, retired when `/finicard` launched:
`/booster-pack`, `/card-collection`, `/sell-card` and `/fuse-cards`. Their
buttons are in `buttons/individualButtons/archived`.

Nothing here is loaded or registered: command and button files are found by a
glob that skips anything under a folder named `archived`. Kept for reference,
and because the v1 collections they read are still in the database.
